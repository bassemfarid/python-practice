# Unit 3 Chapter 1 Question 2 - A Girl Has No Name

Write a program that continuously reads a name *N* from standard input. 

For any standard name, output `hello [N]!` and `NEXT!` on separate lines. Loop this for the next person.

If the input is exactly `A girl has no name` ([Game of Thrones Reference](https://www.youtube.com/watch?v=TgXlQlOrSx8)), output `*sweats profusely*` and terminate the program immediately (do not print `hello` or `NEXT!`).

## Sample Input

```
Jane
John
A girl has no name
```

## Sample Output

```
hello Jane!
NEXT!
hello John!
NEXT!
*sweats profusely*
```
